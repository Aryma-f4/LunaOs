INIT DATA - STATIC DEFINITIONS
File: kernel/init/data.asm
Author: arfy slowy

OVERVIEW
Central data repository for initialization: string constants (task name,
errors, storage path template), semaphores, the VFS directory/file tables,
embedded binaries, and the kernel services startup list.

VARIABLE LAYOUT (in assembly order)

+--------------------------------------------+
| String constants                           |
| - name ("luna"), error messages,           |
|   /dev/hd path template (+ letter)         |
+--------------------------------------------+
| Semaphores (4 bytes)                       |
| - apic, ioapic, smp, ap                    |
+--------------------------------------------+
| Counters (2 bytes)                         |
| - ap_count, apic_id_highest                |
+--------------------------------------------+
| Services list                              |
| - gc, wm, gui, tx, network, HTTP           |
+--------------------------------------------+
| VFS directory structure                    |
| - [/bin] [/etc] [/dev] [/var] + 0 byte     |
+--------------------------------------------+
| VFS files table                            |
| - 14 entries + terminator                  |
|   12 /bin apps + hostname + welcome        |
+--------------------------------------------+
| Embedded binaries                          |
| - 12 apps (incbin "build/*") +             |
|   hostname + welcome                       |
+--------------------------------------------+
| Boot trampoline + support library          |
| - boot (incbin "build/boot")               |
| - library (incbin "build/library")         |
+--------------------------------------------+

STRING CONSTANTS (kernel/init/data.asm)

Task name:
  kernel_init_string_name / _end  - KERNEL_name ("luna"), names the kernel task

Error messages (passed to kernel_panic on fatal init failure):
  kernel_init_string_error_memory       - "Error: Memory map damaged."
  kernel_init_string_error_memory_low   - "Error: Not enough memory."
  kernel_init_string_error_acpi_header  - "Error: RSDP/XSDP not found."
  kernel_init_string_error_acpi         - "Error: RSDT/XSDT not recognized."
  kernel_init_string_error_apic         - "Error: APIC not found."
  kernel_init_string_error_ioapic       - "Error: I/O APIC not found."

Storage path template (init/storage.asm creates /dev/hda, hdb, ...):
  kernel_init_string_storage_ide_hd_path   - "/dev/hd"
  kernel_init_string_storage_ide_hd_letter - "a" (incremented per drive)
  kernel_init_string_storage_ide_hd_end    - end marker

There is no boot-time console output: init runs headless and the first
visible output comes from the GUI.

SERVICES LIST (kernel_init_services_list)

 List format: array of KERNEL_INIT_STRUCTURE_SERVICE entries, terminated
 by dq STATIC_EMPTY:

   +0x00  .pointer  resb 8   -- entry point
   +0x08  .size     resb 8   -- size of service code in bytes
   +0x10  .length   resb 1   -- name string length
   +0x11  .name:             -- name string (variable)
   Entry size: .SIZE = 17 + name length (iterator advances by .SIZE + length)

 Order  Module              Name                      Function
 -----  ------              ----                      --------
   1    kernel_gc           "garbage collector"       Reap finished tasks, close their windows
   2    kernel_wm           "window manager"          Objects, zones, fills, cursor, window syscalls
   3    kernel_gui          "graphical user interface" Taskbar, clock, GUI IPC
   4    service_tx          "network transmit"        Drain queued frames into the NIC TX ring
   5    service_network     "network service"         IPv4/ARP/ICMP/TCP stack, received frames
   6    service_http        "http service"            HTTP responses on TCP port 80

 Services run as kernel tasks, started sequentially in init/services.asm;
 all six are started at boot.

VFS DIRECTORY STRUCTURE (kernel_init_vfs_directory_structure)

Format: [length_byte][path_bytes] per entry, 0x00 terminator

Entry 1: db 0x04, "/bin"     -> creates /bin directory
Entry 2: db 0x04, "/etc"     -> creates /etc directory
Entry 3: db 0x04, "/dev"     -> creates /dev directory
Entry 4: db 0x04, "/var"     -> creates /var directory
End:     db STATIC_EMPTY

VFS FILES TABLE (kernel_init_vfs_files)

Format per entry (KERNEL_INIT_STRUCTURE_VFS_FILE):
+0x00: .data_pointer qword  -- pointer to embedded binary data
+0x08: .size         qword  -- size of binary data in bytes
+0x10: .mode         word   -- file mode bits (KERNEL_VFS_FILE_MODE_*)
+0x12: .length       byte   -- length of path string
+0x13: .path         var    -- path string (e.g. "/bin/shell")
Entry size: .SIZE = 19 + path_length

Table terminated by dq STATIC_EMPTY

Entry  Path                Source label (incbin)
-----  ----                ---------------------
 1-12  /bin/{shell, hello, tm, console, ls, cat, lulu, glaze,
           redia, calculator, tetris, fetch}
       kernel_init_vfs_file_<name> ("build/<name>")
 13    /etc/hostname       kernel_init_vfs_file_hostname ("fs/etc/hostname")
 14    /var/welcome.txt    kernel_init_vfs_file_welcome ("fs/var/welcome.txt")

EMBEDDED BINARY: kernel_init_boot_file
  incbin "build/boot" -- SMP AP boot trampoline
  Loaded at 0x7000 during SMP init. Contains 16-bit real-mode code
  that transitions APs to 64-bit long mode.

EMBEDDED BINARY: kernel_init_library_file
  incbin "build/library" -- support library shared with all processes
  (init/library.asm maps it into every task)
