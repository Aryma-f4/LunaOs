KERNEL DATA STRUCTURES
File: kernel/data.asm
Author: arfy slowy

OVERVIEW
Contains global data for init (semaphore, reserved exec path), GDT,
TSS, and IDT headers used by the kernel, and the video state filled
by init/video.asm.

GDT HEADER
  kernel_gdt_header:
    - limit: 2 bytes (set to STATIC_PAGE_SIZE_byte = 4096)
    - address: 8 bytes (linear address, filled by init)
  
  Note: Limit is set to full page size, not actual GDT size.
        This allows room for future expansion.
  
  Alignment: 8 bytes (QWORD)

TSS (Task State Segment)
  kernel_gdt_tss_bsp_selector: 2 bytes (TSS selector for bootstrap processor)
  kernel_gdt_tss_cpu_selector: 2 bytes (TSS selector for CPU)
  
  TSS Table (kernel_gdt_tss_table):
    - 4 bytes: Reserved (0)
    - 8 bytes: RSP0 = SOFTWARE_BASE_address - 1 page (ring transition stack)
    - 92 bytes: Reserved/interrupt stack table (all zeros)
    
  Size: 104 bytes total
  Alignment: 8 bytes (QWORD)

IDT HEADER
  kernel_idt_header:
    - limit: 2 bytes (set to STATIC_PAGE_SIZE_byte = 4096)
    - address: 8 bytes (linear address, filled by init)
  
  Note: Limit is set to full page size, not actual IDT size.
        This allows room for future expansion.
  
  Alignment: 8 bytes (QWORD)

INIT
  kernel_init_semaphore  - db STATIC_TRUE; cleared by kernel_init when
                           initialization completes (no current readers)

EXEC
  kernel_init_exec     - "/bin/init" (defined but unused; the kernel no
                         longer spawns userspace directly)
  kernel_init_exec_end - end marker for length calculation

VIDEO (filled by init/video.asm from the bootloader's framebuffer info)
  kernel_video_width_pixel    - width in pixels
  kernel_video_height_pixel   - height in pixels
  kernel_video_base_address   - pointer to the framebuffer
  kernel_video_size_byte      - framebuffer size in bytes
  kernel_video_scanline_byte  - bytes per scanline

DEBUG DUMP (kernel/debug.asm)
  kernel_debug_dump           - exception entry: pushes the preserved register frame
                                and dumps the faulting context to COM1
  kernel_debug_serial_char    - print one character to COM1
  kernel_debug_serial_string  - print ecx bytes from rsi to COM1
  kernel_debug_serial_hex     - print rax as hexadecimal
  Strings (each with a matching _end label for length calculation):
    _welcome ("kernel debug dump"), _process_name ("process name (pid): "),
    _pid (" ("), _pid_close (")"), _eflags, _rip, _rax ... _r15

STRUCT: KERNEL_DEBUG_STRUCTURE_PRESERVED
  16 qwords: rax, rbx, rcx, rdx, rsi, rdi, rbp, r8-r15, eflags (rax at the
  lowest address, matching the push order). Has .SIZE. kernel_debug_dump uses
  it to locate the CPU exception frame above the saved registers.

NOTES
These structures are initialized during boot:
- GDT is set up in kernel/init/gdt.asm
- IDT is set up in kernel/init/idt.asm
- TSS provides stack switching for interrupts
- Address fields (dq STATIC_EMPTY) are filled at runtime
