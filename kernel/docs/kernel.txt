KERNEL MAIN
File: kernel/kernel.asm
Author: arfy slowy

OVERVIEW
The main kernel file ties together all subsystems. The bootloader
transfers control to 0x100000 already in 64-bit long mode; init runs
in place (serial, video, memory, paging, ACPI, drivers, services),
releases the init code pages, then enters the idle loop. No userspace
exec is performed — the kernel task remains active and halts in `jmp $`.

BOOT SEQUENCE DETAIL

Step 1: entry at init (kernel.asm, [bits 64], org 0x100000):
  %include "kernel/init.asm"
  - Check SMP semaphore (BSP continues init, AP includes ap.asm)
  - Include init data (strings, services list, VFS tables)
    and the APIC configuration procedure

Step 2: 64-bit init (kernel_init label):
  - serial.asm: COM1 stdlog init (115200 baud, 8N1, FIFO)
  - video.asm: Store framebuffer base, resolution, scanline
  - memory.asm: Parse binary memory map, init page bitmap
  - stream.asm: Pipe table + default output pipe (stdout/stderr/stdlog)
  - acpi.asm: Find RSDP/RSDT or XSDP/XSDT, enumerate CPUs
  - page.asm: Set up PML4, map kernel 1:1/stack/video/APIC
  - library.asm: Share libraries with all processes
  - gdt.asm: Null, CS, DS, TSS descriptors
  - idt.asm: Exceptions (0-31), syscall (0x40 -> kernel_service), spurious (0xFF)
  - rtc.asm: 1024Hz periodic timer, IRQ 8, sti
  - ps2.asm: PS/2 mouse + keyboard init (mouse IRQ 12, keyboard IRQ 1)
  - ipc.asm: IPC message pool allocation
  - vfs.asm: Root magicknot, /bin + /etc + /dev + /var dirs, preload 11 apps + hostname + welcome
  - storage.asm: PCI IDE scan, reset, enumerate, VFS /dev/hd* knots
  - network.asm: PCI NIC detection, i82540EM init
  - task.asm: First kernel task, mount kernel_task on the APIC timer (vector 0x20)
  - services.asm: Start gc, wm, gui, tx, network, http kernel services

Step 3: Finalize:
  - call kernel_init_apic: Full APIC config, TICR = 1024Hz, EOI
  - smp.asm: Wake application processors via INIT/STARTUP IPI
  - Wait for all APs (kernel_init_ap_count == kernel_apic_count)
  - Set kernel_init_semaphore = STATIC_FALSE (init complete)

Step 4: clean: - release init code pages:
  mov ecx, clean - $$           ; size of init code
  mov rdi, KERNEL_BASE_address   ; init code base
  call library_page_from_size    ; convert to page count
  call kernel_memory_release     ; free pages

Step 5: kernel: - enter idle loop:
  call kernel_task_active                       ; current task = kernel
  and word [rdi + KERNEL_TASK_STRUCTURE.flags], ~KERNEL_TASK_FLAG_active
  jmp $                                         ; idle forever

CPU halts in jmp $ (idle loop). The kernel task remains active
so the scheduler keeps ticking. Note: CS ring0 spin loop in
kernel_task removed.

Kernel RAM is mapped 1:1 (identity) from KERNEL_BASE_address; the kernel
stack lives at KERNEL_STACK_address (just below 1 MB), video and APIC
registers are mapped at their physical addresses.

CONFIGURATION CONSTANTS

KERNEL_BASE_address         0x0000000000100000  (1MB, kernel load address)
KERNEL_STACK_address        KERNEL_BASE_address - 8 KiB (kernel/init stack)
KERNEL_STACK_pointer        KERNEL_STACK_address + 4 KiB
SOFTWARE_BASE_address       0x0000100000000000  (userspace code base)

kernel_init_exec ("/bin/init") is defined in kernel/data.asm but unused;
the kernel no longer spawns userspace directly.
