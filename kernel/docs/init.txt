INITIALIZATION CHAIN
File: kernel/init.asm
Author: arfy slowy

OVERVIEW
Main initialization module that includes all init components in the correct order.
Handles transition from 32-bit to 64-bit mode, SMP application processor boot, and
complete kernel initialization.

STRUCTURE

SMP Boot Check (top of init.asm):
  1. Check kernel_init_smp_semaphore
     STATIC_FALSE -> BSP path (continue init)
     STATIC_TRUE  -> AP path, include ap.asm (application processor init)
     Falls through to .entry to continue boot

Definitions included before kernel_init (data + APIC procedure):
  2. kernel/init/data.asm
     Init variables and strings: services list, VFS directory/file tables,
     embedded application binaries, kernel_init_boot_file (SMP trampoline),
     kernel_init_ap_semaphore for AP synchronization

  3. kernel/init/apic.asm
     kernel_init_apic procedure — Local APIC configuration (flat mode,
     spurious vector, LVT timer); called inline after services.asm,
     before smp.asm

64-bit Initialization (kernel_init):
  4. kernel/init/serial.asm
     Initialize serial port COM1 as stdlog (115200 baud, 8N1, FIFO enabled)
     Calls: driver_serial

  5. kernel/init/video.asm
     Store framebuffer info from the bootloader's VESA mode block
     Output: kernel_video_base_address, width/height (pixels),
             kernel_video_size_byte, kernel_video_scanline_byte

  6. kernel/init/memory.asm
     Parse the binary memory map and initialize the page bitmap
     Uses: memory map array passed by the bootloader
     Output: kernel_memory_map_address, page bitmap
     Error: kernel_init_string_error_memory -> kernel_panic

  7. kernel/init/stream.asm
     Create the pipe table and default output pipe
     Output: kernel_stream_address, kernel_stream_out_default (stdout/stderr/stdlog)

  8. kernel/init/acpi.asm
     Initialize ACPI and enumerate CPUs
     Finds: RSDP, RSDT, MADT
     Output: kernel_apic_base_address, kernel_apic_count, IO-APIC info

  9. kernel/init/page.asm
     Set up paging and virtual memory mappings
     Allocates: PML4 table
     Maps: kernel RAM 1:1 from KERNEL_BASE_address, kernel stack,
           video memory, APIC + IO-APIC registers

  10. kernel/init/library.asm
      Share the libraries with all processes

  11. kernel/init/gdt.asm
     Initialize Global Descriptor Table
     Sets up: null, CS, DS, TSS descriptors
     Loads: GDT and task register

  12. kernel/init/idt.asm
      Initialize Interrupt Descriptor Table
      Sets up: exception handlers (0-31), syscall gate (vector 0x40 -> kernel_service),
               spurious handler (vector 0xFF)
      Loads: IDT via LIDT

  13. kernel/init/rtc.asm
      Initialize Real Time Clock
      Configures: 1024Hz periodic interrupts
      Connects: IRQ 8 to IO-APIC
      Enables interrupts (sti)

   14. kernel/init/ps2.asm
      Initialize PS/2 mouse and keyboard
      Mouse init (before keyboard):
        1. Drain stale data from controller
        2. Get configuration byte, enable second port interrupt,
           clear second port clock disable
        3. Reset mouse device, wait for ACK + self-test success,
           read mouse type ID (standard/wheel/5-button)
        4. Set default settings, enable packet streaming
        5. Mount IRQ 12 handler (driver_ps2_mouse) to IDT + IO-APIC
      Keyboard init (after mouse):
        6. Mount IRQ 1 handler (driver_ps2_keyboard) to IDT + IO-APIC

  15. kernel/init/ipc.asm
      Initialize IPC message pool
      Allocates: IPC pool page
      Must run before VFS, network and task init

  16. kernel/init/vfs.asm
      Initialize Virtual File System
      Allocates: root directory page (pointer saved in kernel_vfs_magicknot .data)
      Creates: root directories (kernel_init_vfs_directory_structure: /bin, /etc, /dev, /var)
      Preloads: 12 applications (shell, hello, tm, console, ls, cat, lulu, glaze,
                redia, calculator, tetris, fetch) + /etc/hostname + /var/welcome.txt
      Runs after IPC, before network

  17. kernel/init/storage.asm
      Initialize storage subsystem
      Scans PCI for IDE controller (class 0x0101)
      Calls driver_ide_init: resets both IDE channels (SRST),
      enumerates master/slave drives via IDENTIFY command,
      detects LBA48 support, populates driver_ide_devices table
      Creates: VFS block device knots for each detected drive
      Stores: byte size in knot (sectors * 512)
      Runs after VFS, before network

  18. kernel/init/network.asm
       Detect and initialize NIC hardware
       Scans PCI for network class, matches i82540EM vendor/device
       Allocates: port table page, stack address page
       Calls: driver_pci_find_class_and_subclass, driver_nic_i82540em

  19. kernel/init/task.asm
       Initialize tasking system
       Creates: the task queue, active task list and the first (kernel) task
       Mounts: kernel_task handler on the APIC timer interrupt (vector 0x20)

   20. kernel/init/services.asm
         Start kernel services in list order — garbage collector, window manager,
         GUI, network transmit, network service, HTTP service

   (inline) call kernel_init_apic — set TICR = DRIVER_RTC_Hz, send EOI

   21. kernel/init/smp.asm
      Map and copy boot trampoline (kernel/init/boot.asm) to 0x7000
      Set kernel_init_smp_semaphore to STATIC_TRUE
      Send INIT IPI to all APs (ICR = 0x00004500)
      Wait 10ms for APs to complete INIT
      Send STARTUP IPI with vector 0x07 to each AP (ICR = 0x00004607)
      APs start at 0x7000: boot.asm 16-bit -> 32-bit -> 64-bit, then
      jmp 0x100000 (kernel entry falls into ap.asm)
      Note: sti moved to init/rtc.asm (step 13), removed from init.asm

AP boot path (boot.asm -> kernel entry -> ap.asm):
  boot.asm (copied to 0x7000 as kernel_init_boot_file):
  - Enter 32-bit protected mode, enable PAE, load boot PML4
  - Enable long mode (EFER.LME), enable paging
  - Far jump to 64-bit mode, jmp 0x100000 (kernel entry;
    kernel_init_smp_semaphore is set -> falls into ap.asm)
  ap.asm:
  - Reload kernel GDT, set LAPIC task priority, get APIC ID
  - Calculate and load per-CPU TSS selector
  - Load IDT
  - Wait on kernel_init_ap_semaphore
  - Allocate AP PML4 page and stack via kernel_page_map_logical
  - Merge page tables with BSP via kernel_page_merge
  - Load merged CR3, set stack pointer
  - Release semaphore, call kernel_init_apic
  - Get APIC ID, find task slot
  - Increment kernel_init_ap_count (signal BSP of completion)
  - Jump to kernel_task.ap_entry

Final Steps (after all init modules):
  - call kernel_init_apic (full APIC initialization)
  - Set APIC TICR register to DRIVER_RTC_Hz (1024Hz timer)
  - Send EOI to clear any pending interrupt
  - smp.asm -> wake application processors
  Note: sti was moved from here to init/rtc.asm (step 13)
  - Wait for all APs: re-read kernel_init_ap_count on each
    iteration, compare against kernel_apic_count
   - Set kernel_init_semaphore to STATIC_FALSE (init complete)
   - Jump to clean: (in kernel.asm) — releases init code pages via kernel_memory_release,
     then enters idle loop (kernel_task_active + jmp $)

ERROR HANDLING
Each init module checks for errors and calls kernel_panic /
kernel_panic_memory on failure.
