ROOT CONFIGURATION
File: config.asm
Author: arfy slowy

OVERVIEW
Global constants and macros used throughout the kernel. This file defines
fundamental sizes, shifts, masks, scancode constants, terminal escape
sequences, booleans, and the Everblush color palette.

  STATIC_PAGE_SIZE_byte   = 0x1000 (4096 bytes = 4KB)
  STATIC_PAGE_SIZE_shift  = 12 (2^12 = 4096)

TERMINAL SEQUENCES (%define, min length STATIC_SEQUENCE_length_min = 5)
  STATIC_SEQUENCE_CLEAR          "^[t0]"   clear the console/terminal space
  STATIC_SEQUENCE_CURSOR         "^[t1;__--]" set cursor at xxxx(16),yyyy(16)
  STATIC_SEQUENCE_CURSOR_ENABLE  "^[t2;0]"  enable the text cursor
  STATIC_SEQUENCE_CURSOR_DISABLE "^[t2;1]"  disable the text cursor
  STATIC_SEQUENCE_CURSOR_PUSH    "^[t2;2]"  remember the position
  STATIC_SEQUENCE_CURSOR_POP     "^[t2;3]"  restore the position
  STATIC_SEQUENCE_CURSOR_RESET   "^[t2;4]"  reset the cursor lock
  STATIC_SEQUENCE_CURSOR_UP/DOWN/LEFT/RIGHT "^[t2;C/D/E/F]"
  STATIC_SEQUENCE_CLEAR_LINE     "^[t3]"
  STATIC_SEQUENCE_SCROOL_UP      "^[t4;__--]" scroll up by "__" lines
  STATIC_SEQUENCE_SCROOL_DOWN    "^[t5;__--]" scroll down by "__" lines
  STATIC_SEQUENCE_NUMBER         "^[t6;-=~________]" value in a chosen base
  Color sequences: "^[c07]" default, "^[c*0..F]" foreground,
  "^[c0..F*]" background (0-9,A-F = black, red, green, brown,
  blue, magenta, cyan, gray_light, gray, red_light, green_light,
  yellow, blue_light, magenta_light, cyan_light, white)

STRUCTURE: STATIC_STRUCTURE_BLOCK
  Used for the linked-list data chain of a VFS file
  Size: one page (4096 bytes)
  Fields:
    .data: 4088 bytes of usable data
    .link: 8 bytes for next block pointer (at the top of the page)
