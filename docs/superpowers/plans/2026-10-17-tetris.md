# Tetris Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the non-running Tetris skeleton into a fully playable game with score label, next-piece preview, and escalating drop speed.

**Architecture:** Single poll loop in `tetris.asm` (bosu_event → input → RTC gravity → full redraw when dirty). Game rules live in `software/tetris/game.asm`, all pixel work in `software/tetris/draw.asm`. No kernel changes; everything renders through `tetris_window.address` + the Bosu flush/update cycle.

**Tech Stack:** NASM x86-64 flat binaries (`nasm -f bin`), LunaOs Bosu window library, RTC microsecond time (1024 ticks/s), QEMU + QMP screendumps as the test oracle.

**Spec:** `docs/superpowers/specs/2026-10-17-tetris-design.md` — every constant and limit below is copied from it.

## Global Constraints

- Build: `rm -f build/* && make all` from repo root (Makefile misses `%include` deps — always clean the targets).
- Verification is ALWAYS a real boot: restart QEMU on `build/luna_disk.raw` headless with QMP, then `screendump` + PIL diff. No unit framework exists; a screenshot that shows the expectation is the test.
- QEMU restart block (used by every task):
  ```bash
  pkill -f '[q]emu-system-x86_64' || true; sleep 1
  rm -f /tmp/opencode/echo-check/qmp.sock
  qemu-system-x86_64 -drive file=build/luna_disk.raw,media=disk,format=raw -m 16 -smp 2 \
    -rtc base=localtime -display none \
    -qmp unix:/tmp/opencode/echo-check/qmp.sock,server,nowait \
    -serial file:/tmp/opencode/echo-check/qemu.log &
  ```
- `STATIC_TRUE equ 0x00`, `STATIC_FALSE equ 0x01` (inverted codebase-wide). Prefer literal `STATIC_EMPTY` (0) for "no flag".
- Key codes: arrows `STATIC_SCANCODE_LEFT/RIGHT/UP/DOWN` (0xE04B/4D/48/50), space `STATIC_SCANCODE_SPACE` (0x20), Enter `STATIC_SCANCODE_RETURN` (0x0D), letters arrive as ASCII (`'r'` = 0x72, `'R'` = 0x52).
- Colors are `0x00RRGGBB` literals. If a screendump shows red/blue swapped, swap the palette table once and re-verify (Review Focus #4).
- GPG signing times out in this environment: commit with `git -c commit.gpgsign=false commit ...`.
- No wall kicks, no kernel edits, no new dependencies (spec).

## Review Focus

1. **Window buffer overrun** — Bosu sizes the data buffer from the *declared* width/height (+2 border); elements are never clipped. The skeleton declared `TETRIS_WINDOW_HEIGHT_pixel = 140` while its playground spanned y=18..158 — a 17-row overrun that was hidden because nothing ever drew. **Test:** Task 1 Step 1 pins the formula `declared = HEADER + content`; Task 2 screenshot shows the bottom border row intact and labels unwrapped.
2. **Score label overflow** — `integer_to_string` writes unbounded digits straight into an 11-byte element buffer; an overflow smashes the next element struct. **Test:** Task 2 Step 2 (draw code) clamps every displayed value to `99999` before conversion; Task 3 screenshot shows `SCORE`-style output with the lines/level labels intact beneath.
3. **Key release codes acting as input** — releases arrive as 0x80/E0-variant codes; a missed `cmp` chain that falls into a handler causes phantom moves/rotation storms. **Test:** Task 2 handlers are exact `je` dispatch with a fall-through `jmp .end`; Task 2 Step 5 screenshot after tap+release pairs shows exactly one movement per press.
4. **Color byte order** — palette literals may render BGR instead of RGB. **Test:** Task 2 Step 6: the O piece (yellow `0x00FFFF00`) must appear yellow, not blue; swap table if not.
5. **Collision edge semantics** — empty pattern rows must NOT collide (piece would rest one row high, leaving gaps), while the floor row (index 22, `0x0FFF`) must collide. **Test:** Task 2 hard-drop screenshot shows cells flush on the bottom row; Task 3 line-fill proves rows lock adjacent.

- [ ] **Step 4: Rewrite `software/tetris/collision.asm` — real result contract**

Full replacement:

```nasm
; entry:
;	bx - block pattern (active rotation state, low word)
;	r8 - position on the X axis (bit shift into the platform row)
;	r9 - position on the Y axis (platform row of pattern row 0)
; exit:
;	CF - set on collision, clear when the position is free
;	r8, r9, bx preserved
tetris_collision:
 ; save the original registers
 push rax
 push rbx
 push rcx
 push rdx
 push r9 ; also restored per call, keeps the entry value

 ; local variable
 push TETRIS_BRICK_STRUCTURE_height

.loop:
 ; fetch the current row of the block structure (zero-extended: ah must not
 ; leak into the shifted value — the original mov al, bl left it as garbage)
 movzx eax, bl
 and al, STATIC_BYTE_LOW_mask

 ; move the row of the block structure into the place
 mov cl, r8b
 shl ax, cl

 ; an empty row can never collide (keeps trailing gaps above the floor clean)
 test ax, ax
 jz .next

 ; cells pushed outside the playfield (bit 0 or bits 11..15)?
 mov dx, ax
 and dx, 1111100000000001b
 jnz .collision

 ; past the floor row (index 22)?
 cmp r9, TETRIS_PLAYGROUND_HEIGHT_brick
 ja .collision

 ; fetch the board space line matching the line position of the block structure
 mov rdx, tetris_brick_platform
 mov dx, word [rdx + r9 * STATIC_WORD_SIZE_byte]

 ; did a collision occur?
 test ax, dx
 jnz .collision

.next:
 ; next line of the block pattern structure
 shr bx, STATIC_MOVE_AL_HALF_TO_LOW_shift

 ; next line of the board space
 inc r9

 ; has the whole block pattern been processed?
 dec qword [rsp]
 jnz .loop ; no

 ; free position
 clc
 jmp .end

.collision:
 stc

.end:
 ; free the local variable
 pop rax

 ; restore the original registers
 pop r9
 pop rdx
 pop rcx
 pop rbx
 pop rax

 ; return from the procedure
 ret
```

- [ ] **Step 1: Create `software/tetris/game.asm`**

```nasm
; start a new game: empty board, zeroed counters, default title
tetris_reset:
 push rax
 push rcx
 push rdi
 push rsi

 ; empty platform with walls
 mov rdi, tetris_brick_platform
 mov ax, 0000100000000001b
 mov ecx, TETRIS_PLAYGROUND_HEIGHT_brick
 rep stosw
 ; floor
 mov ax, 0000111111111111b
 stosw

 ; clear the cell colors
 mov rdi, tetris_cell_color
 xor eax, eax
 mov ecx, TETRIS_PLAYGROUND_HEIGHT_brick * TETRIS_PLAYGROUND_WIDTH_brick
 rep stosb

 ; state
 mov qword [tetris_score], STATIC_EMPTY
 mov qword [tetris_lines], STATIC_EMPTY
 mov qword [tetris_level], STATIC_EMPTY
 mov qword [tetris_interval], TETRIS_GRAVITY_initial
 mov qword [tetris_brick_pattern], STATIC_EMPTY
 mov qword [tetris_brick_next], STATIC_EMPTY
 mov byte [tetris_brick_piece], STATIC_EMPTY
 mov byte [tetris_brick_next_piece], STATIC_EMPTY
 mov byte [tetris_game_over], STATIC_EMPTY
 mov byte [tetris_tick], 0x01

 ; default title
 mov ecx, 0x06
 mov rsi, tetris_string_title
 mov rdi, tetris_window
 macro_library LIBRARY_STRUCTURE_ENTRY.bosu_header_set

 pop rsi
 pop rdi
 pop rcx
 pop rax
 ret

; place the active piece and refresh the preview
tetris_spawn:
 push rax
 push rbx

 ; promote the pending piece, if any (0 only before the first spawn)
 mov rax, qword [tetris_brick_next]
 test rax, rax
 jz .generate
 mov qword [tetris_brick_pattern], rax
 mov al, byte [tetris_brick_next_piece]
 mov byte [tetris_brick_piece], al
 jmp .preview

.generate:
 call tetris_random_block ; rbx - full pattern, [tetris_random_index] - piece
 mov qword [tetris_brick_pattern], rbx
 mov al, byte [tetris_random_index]
 mov byte [tetris_brick_piece], al

.preview:
 call tetris_random_block
 mov qword [tetris_brick_next], rbx
 mov al, byte [tetris_random_index]
 mov byte [tetris_brick_next_piece], al

 ; starting position of the block
 mov r8, TETRIS_BRICK_START_POSITION_x
 mov r9, TETRIS_BRICK_START_POSITION_y

 mov byte [tetris_tick], 0x01

 pop rbx
 pop rax
 ret

; entry: dl - shift on the X axis (signed), dh - shift on the Y axis (signed)
; exit: CF - set when blocked, clear when moved (and tick set)
tetris_try_move:
 push rax
 push rbx

 ; remember the original position
 mov qword [tetris_position_backup_x], r8
 mov qword [tetris_position_backup_y], r9

 ; trial position
 movsx rax, dl
 add r8, rax
 movsx rax, dh
 add r9, rax

 ; free at the trial position?
 mov bx, word [tetris_brick_pattern]
 call tetris_collision
 jnc .moved

 ; blocked: restore the original position
 mov r8, qword [tetris_position_backup_x]
 mov r9, qword [tetris_position_backup_y]
 stc
 jmp .end

.moved:
 mov byte [tetris_tick], 0x01
 clc

.end:
 pop rbx
 pop rax
 ret

tetris_try_rotate:
 push rax
 push rbx

 ; the original state
 mov rax, qword [tetris_brick_pattern]

 ; next rotation state (4 words = 4 states, cycling)
 rol qword [tetris_brick_pattern], 16

 ; free after rotating?
 mov bx, word [tetris_brick_pattern]
 call tetris_collision
 jnc .rotated

 ; restore the original state
 mov qword [tetris_brick_pattern], rax
 stc
 jmp .end

.rotated:
 mov byte [tetris_tick], 0x01
 clc

.end:
 pop rbx
 pop rax
 ret

; write the resting piece into the platform and the color board
tetris_lock:
 push rax
 push rbx
 push rcx
 push rdx
 push rsi
 push rdi

 pop rcx
 pop rax

 call tetris_input

.timer:
 ; frozen after a game over (Task 4 sets the flag)
 cmp byte [tetris_game_over], STATIC_EMPTY
 jne .render

 ; gravity due?
 mov ax, KERNEL_SERVICE_SYSTEM_time
 int KERNEL_SERVICE
 cmp eax, dword [tetris_next_tick]
 jb .render ; not yet

 ; re-arm, fall one row (or settle when blocked)
 call tetris_timer_next
 xor edx, edx
 mov dh, 0x01
 call tetris_try_move
 jnc .render
 call tetris_settle

.render:
 ; redraw only when the state changed
 cmp byte [tetris_tick], STATIC_EMPTY
 je .loop
 mov byte [tetris_tick], STATIC_EMPTY
 call tetris_draw
 jmp .loop

 ; ---- input ----
 ; entry: dx - key code
tetris_input:
 push rax

 ; after a game over only a restart is accepted
 cmp byte [tetris_game_over], STATIC_EMPTY
 jne .over_state

 cmp dx, STATIC_SCANCODE_LEFT
 je .left
 cmp dx, STATIC_SCANCODE_RIGHT
 je .right
 cmp dx, STATIC_SCANCODE_UP
 je .up
 cmp dx, STATIC_SCANCODE_DOWN
 je .down
 cmp dx, STATIC_SCANCODE_SPACE
 je .drop
 jmp .end ; unknown key (incl. releases): ignore

.left:
 mov dl, -0x01
 xor dh, dh
 call tetris_try_move
 jmp .end

.right:
 mov dl, 0x01
 xor dh, dh
 call tetris_try_move
 jmp .end

.up:
 call tetris_try_rotate
 jmp .end

.down:
 xor edx, edx
 mov dh, 0x01
 call tetris_try_move
 jnc .retime
 call tetris_settle ; resting against the stack: lock immediately
.retime:
 call tetris_timer_next
 jmp .end

.drop:
 xor edx, edx
 mov dh, 0x01
.hard:
 call tetris_try_move
 jnc .hard ; keep falling
 call tetris_settle
 jmp .end

.over_state:
 cmp dx, "r"
 je .restart
 cmp dx, "R"
 je .restart
 cmp dx, STATIC_SCANCODE_RETURN
 jne .end

.restart:
 call tetris_reset
 call tetris_spawn
 call tetris_timer_next

.end:
 pop rax
 ret

.close:
 ; terminate the program
 xor ax, ax
 int KERNEL_SERVICE

 macro_debug "software: tetris"

 %include "software/tetris/random.asm"

 dec rdx
 jns .cshift

 ; the vacited top color row is empty
 mov rdi, tetris_cell_color
 xor eax, eax
 mov rcx, TETRIS_PLAYGROUND_WIDTH_brick
 rep stosb

 inc qword [tetris_cleared]
 jmp .row ; the row above moved down: re-check this index

.next:
 dec r9
 jns .row

 pop rdi
 pop rsi
 pop rdx
 pop rcx
 pop rax
 ret

; apply the points and advance the level / drop interval
tetris_scoring:
 push rax
 push rbx
 push rcx
 push rdx

 mov rax, qword [tetris_cleared]
 test rax, rax
 jz .end ; nothing cleared

 ; score += table[count - 1] * (level + 1)   [level before this clear]
 mov rbx, qword [tetris_level]
 inc rbx
 imul rax, qword [tetris_score_table + rax * STATIC_QWORD_SIZE_byte - STATIC_QWORD_SIZE_byte]
 add qword [tetris_score], rax

 ; lines += count
 mov rax, qword [tetris_cleared]
 add qword [tetris_lines], rax

 ; level = lines / 10
 mov rax, qword [tetris_lines]
 xor edx, edx
 mov ecx, STATIC_NUMBER_SYSTEM_decimal
 div rcx
 mov qword [tetris_level], rax

 ; interval = max(minimum, initial - level * step)
 imul rax, TETRIS_GRAVITY_step
 mov rcx, TETRIS_GRAVITY_initial
 sub rcx, rax
 cmp rcx, TETRIS_GRAVITY_minimum
 jge .interval
 mov rcx, TETRIS_GRAVITY_minimum
.interval:
 mov qword [tetris_interval], rcx

.end:
 pop rdx
 pop rcx
 pop rbx
 pop rax
 ret
```

Assemble-time sanity: `.row`, `.shift`, `.cshift`, `.next` are local to `tetris_clear_lines`; the platform-shift loop indexes with `rcx`, the color-shift loop with `rdx`; the proc body is exactly the order shown, ending in `.next: dec r9 / jns .row`.
